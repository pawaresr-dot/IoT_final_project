## ผลที่ยืนยัน
- ผู้ทดลองยืนยันโหมดคงที่จับ ยก ย้าย และปล่อยสำเร็จ 1 รอบที่มีคลิป
- วิธีปรับท่าตามภาพอีกแบบมี 2 สำเร็จ/4 รอบในคลิปที่แนบ ห้ามรวมเป็นผลของโหมดสุดท้าย
- ACT ฝึกแล้วแต่ยังหยิบจริงไม่สำเร็จ ระบบสุดท้ายไม่ใช่ ACT
- ไม่รองรับตำแหน่งอิสระทั้งตารางหรือเลือกย้ายครบทุกช่อง

## โครงสร้าง
- docs/: รายงาน บทพูด ลำดับไฟล์ และรายการต้นฉบับ
- evidence/: คลิปและ JSON ทั้งสำเร็จและพลาด 5 รอบ
- project/: ซอร์สและเอกสารประวัติ พร้อม reference JSON สำหรับ --fixed
- archives/: คลังเต็มแยกนอก repository มีข้อมูลฝึกและ checkpoint ไม่ยัดไฟล์ใหญ่ลง Git

## การรันบนฮาร์ดแวร์เดิม
โค้ดอ้างอิง Python environment lerobot และ LeRobot 0.6.1 ตรวจเวอร์ชันใน docs/04_environment.txt
ต้องแก้พอร์ต/เส้นทางให้ตรงเครื่องและมี calibration ก่อนรัน ห้ามใช้ค่าท่าของแขนนี้กับแขนอื่นโดยตรง
เปิดกล้อง pi_camera_preview.py และ controller hand_teach.py ตามรายงานก่อน จาก project/ ใช้ `python record_local_pick.py --fixed` เพื่อรันทดลองพร้อมอัดคลิป
คำสั่งนี้ทำให้แขนเคลื่อนจริง โปรแกรมมอเตอร์ต้องครอง serial เพียงตัวเดียว

## ข้อมูลทั้งหมด
ชุด GitHub ไม่รวม dataset/checkpoint ขนาดใหญ่ แต่ต้นฉบับทั้งหมดเก็บในคลัง ZIP แยกและมี SHA-256 ต่อไฟล์ใน docs/05_full_file_inventory.csv ไม่มีการลบข้อมูลดิบ
เอกสารเก่าใน project/ เป็นบันทึกประวัติ ไม่ใช่สถานะล่าสุด ให้ยึดรายงานและ result.json ของแต่ละรอบ
