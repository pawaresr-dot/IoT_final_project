# แผนส่งงานภายใน 2 วัน

## ขอบเขตขั้นต่ำที่ต้องทำให้ครบ

ผู้ใช้เลือกช่องต้นทาง → แขนคีบวัตถุน้ำหนักเบา → ยกออกจากตาราง → วางจุดคงที่
เริ่มพิสูจน์หนึ่งช่องก่อน แล้วจึงเพิ่มช่องอื่น ไม่เรียกการทำได้หนึ่งช่องว่าเสร็จครบสี่ช่อง
กล้องใช้แสดงภาพและตรวจการมีวัตถุ ไม่ฝึกโมเดลใหม่ในรอบส่งนี้
พักแขนสอนไว้ก่อน: ยังมีข้อผิดพลาดแรงดันจากกริปเปอร์ของแขนสอน

## ลำดับงานที่เหลือ

1. ทดสอบกริปเปอร์ follower เปิด–กลับให้ผ่าน แล้วทดสอบคีบวัตถุจริง
2. ตรวจว่าฐานแขน ตาราง และจุดวางยังตรงกับท่าที่บันทึก หากเปลี่ยนให้แก้เฉพาะท่าที่จำเป็น ไม่ calibration ใหม่ทั้งหมด
3. รวมเส้นทางเข้าจับ → คีบ → ยก → ย้ายออก → ปล่อย เป็นหนึ่งรอบ
4. ทดสอบครบวงจร 3 ครั้ง เก็บสำเร็จ/ล้มเหลว เวลาต่อรอบ และเหตุขัดข้องจริง
5. เชื่อมปุ่มเลือกช่องเข้ากับเส้นทางที่ทดสอบผ่าน ช่องที่ยังไม่ผ่านให้ระบุว่ายังไม่พร้อม
6. บันทึกวิดีโอและภาพหน้าจอ เก็บผลทดสอบ แล้วเติมรายงาน

## การแบ่งเวลา

- วันแรก: ให้คีบและย้ายออกได้หนึ่งช่องก่อน ถ้ายังไม่ได้ หยุดเพิ่มฟีเจอร์อื่น
- วันที่สองช่วงแรก: ทดสอบซ้ำและเพิ่มช่องเท่าที่พิสูจน์ได้
- วันที่สองช่วงท้าย: หยุดเปลี่ยนโครงสร้างโปรแกรม เก็บวิดีโอและจัดรายงาน

## เดโมสำรองที่ต้องบอกตามจริง

หากหยิบของครบวงจรยังไม่ผ่าน ให้แสดงกล้องตรวจช่อง การเลือกคำสั่ง และการขยับแขนเปล่า
แยกจากกัน พร้อมระบุว่าส่วนคีบและบูรณาการยังไม่สำเร็จ ห้ามใช้การจำลองแทนผลทดลองจริงโดยไม่ติดป้าย

## โปรแกรมที่เกี่ยวข้อง

- `pi_camera_preview.py`: ภาพสดและตรวจตาราง พอร์ต 8765
- `hold_arm_pose.py`: ควบคุม follower และเส้นทางทดลอง พอร์ต 8766
- `gripper_probe.py`: ตรวจอย่างเดียวเป็นค่าเริ่มต้น; `--move` ทดสอบเปิด–กลับสั้น ๆ เฉพาะ gripper
- `leader_follower_bridge.py`: พักไว้ ไม่ใช่ข้อกำหนดของเดโม follower โดยตรง

ห้ามเปิดสองโปรแกรมที่ใช้ serial ของ follower พร้อมกัน
ท่าที่บันทึกเป็น joint-space ไม่ใช่เส้นทางหลบสิ่งกีดขวางอัตโนมัติ
